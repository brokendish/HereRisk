## 2. 質問した利用形態

国土地理院の**DEM10B標高タイル**（`dem_png`）について、次の利用形態に測量法第29条・第30条に基づく承認申請が必要かを質問した。

1. 標高タイルを事前に取得し、サーバーに保存する。
2. PNGの画素値から標高へ変換する。
3. **指定した1地点の標高値だけを返すWeb API**を提供する。
4. 上記を行う標高取得プログラムを使用する。

PNGや変換後のデータ（正規化JSON等）そのものを配布する形態は、質問に含まれていない。

## 3. 回答の内容

| 事項 | 回答 |
|---|---|
| 標高タイルの位置付け | 「基本測量成果以外で出典の記載のみで利用可能なもの」 |
| 測量法に基づく承認申請 | **不要** |
| 標高取得プログラム | 質問に挙げたプログラムの場合、同じく承認申請は**不要** |
| 条件 | 国土地理院コンテンツ利用規約と、地理院タイル一覧の各タイルの備考欄を遵守し、出典を明示すること |
| 留保 | 場合により判断が変わる可能性がある旨の留保がある |

公式の参照先（回答で示されたもの）:

- 測量法第29条・第30条の承認申請（明示）: <https://www.gsi.go.jp/LAW/2930-meizi.html>
- 国土地理院コンテンツ利用規約: <https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html>
- 地理院タイル一覧: <https://maps.gsi.go.jp/development/ichiran.html>

## 4. 回答の解釈の区別

本回答で確認できたことと、引き続き守るべき条件を区別する。

| 区分 | 内容 | 状態 |
|---|---|---|
| **測量法上の承認申請** | 質問した利用形態（第2章）について、第29条・第30条の承認申請は不要 | **解消**（回答による） |
| **利用規約の遵守** | 国土地理院コンテンツ利用規約に従うこと（加工した場合の加工表示、国土地理院が作成したかのような態様で公表しないこと等を含む） | **継続して必要**。承認申請が不要であることは、規約の遵守が不要であることを意味しない |
| **地理院タイル一覧の備考欄の遵守** | 標高タイルの備考欄の記載に従うこと | **継続して必要** |
| **出典の明示** | 出典を明示すること | **継続して必要**。HereRiskでの最終的な出典文言は未確定（第5章） |

**結論: DEM10Bについて、測量法上の承認申請の要否は解消した**（第2章の利用形態に限る）。ただし、公開に必要なその他の条件がすべて満たされたとは扱わない。残る条件は次のとおり。

- 出典文言の確定
- 規約と備考欄の遵守の確認
- 第三者の権利
- 公開資格の判定
- OWNERの公開承認

## 6. 適用範囲と留保

- **適用範囲**: 本回答は、第2章の利用形態（DEM10B標高タイルの事前取得・サーバー保存・画素値からの標高変換・指定1地点の標高値だけを返すWeb API、およびその標高取得プログラム）に限る。
  - 次の場合は、本回答をそのまま適用せず、改めて確認する。
    - 利用形態を変える場合（PNGや変換後データの配布、複数地点・面的な値の提供、地図としての表示など）
    - 対象データを変える場合（DEM1A・5A等の他の標高データ、他の地理院タイル）
- **留保**: 回答には、場合により判断が変わる可能性がある旨の留保がある。利用形態の変更、規約・備考欄の改正、国土地理院の案内の変更があった場合は、再確認する。
- **Flood（A31a・N03）への非適用**: 本回答は国土地理院のDEM10B標高タイルに関するものである。国土数値情報のA31a（洪水浸水想定区域）とN03（行政区域）の利用条件には**適用しない**。A31a・N03の利用条件の未解決事項（ZIP内メタデータの「国土情報利用約款を参照」とデータページの「CC_BY_4.0」の差異など）は、引き続き未解決である。
