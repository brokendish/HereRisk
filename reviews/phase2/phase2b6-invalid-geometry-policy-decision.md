## 1. 調査の実測事実（Phase 2-B.3〜B.5）

| 項目 | 件数 |
|---|---:|
| 対象26成果品（Phase 2-A.4の対象）のPolygon | 1,508,379 |
| 有効 | 1,484,991 |
| 無効 | 23,388（1.55%） |
| 派生形状の適用候補（調査PoCの条件(a)〜(e)を満たした） | 23,342 |
| 解釈不一致（条件(c)の不成立） | 46 |

| 無効の分類（重複あり） | 件数 |
|---|---:|
| 自己接触（頂点‐頂点） | 23,294 |
| 内部の非連結 | 94 |
| 真の辺交差・辺の重複・スパイク・面積0のリング・頂点‐辺の接触 | 0 |

- 26成果品のすべてに無効形状がある（無効の割合は0.16%〜2.31%）。
- 23,342件は、調査PoC（Phase 2-B.4・B.5）で条件(a)〜(e)を満たした。具体的には、次の3方式の派生形状が全件で位相的に一致し、すべて有効で、元にない頂点がなかった:
  - 整数演算によるリングの分割・再構成（C-3）
  - `make_valid(linework)`
  - `make_valid(structure)`
- 46件は、偶奇規則・GeoJSONの構造による解釈と、非ゼロ巻き数規則による解釈が異なる。
  - いずれもMultiPolygonの構成Polygonである。
  - 外周と同じ向きの穴を持つ。穴の数はPhase 2-B.4の1件で4個、Phase 2-B.5の45件で199個、計203個。
  - Phase 2-B.5の199個はすべて、同じFeatureの他の構成（島）を内側に含む。Phase 2-B.4の4個が島を含むかは確認していない。
- Shapely（GEOS 3.14.1）と整数の参照判定器の有効／無効の判定は、全件で一致した。
- **これらの件数は、調査した26成果品についての測定値であり、全A31aデータで保証されたものではない。** 関東地方整備局ZIPの残りの成果品・隣接県では、未出現の分類が現れうる。条件(a)〜(e)の判定は調査用のコードによるもので、製品の検証器による判定ではない。

## 2. 採用する設計原則

Phase 2-B.6の指示書でOWNERが示した原則を、契約案に反映した。契約案の正式採用は未了である。

| 原則 | 内容 | 反映箇所 |
|---|---|---|
| 原則1 原典保持 | 無効な幾何形状を含んでも原典を改変しない。原典を正しく保存・解釈できない異常は従来どおり失敗。**原典の忠実な正規化と、Flood判定への使用可能性は別の合格条件** | N §1.4（P-1・P-2）、§5、§8 |
| 原則2 妥当性の分類 | 全Polygonに妥当性の状態（`valid`・`invalid_classified`・`invalid_unclassified`・`validation_error`）を記録。Feature件数と構成Polygon件数を分離 | N §9.3〜§9.6 |
| 原則3 既定では判定保留 | 無効形状は初期状態で判定保留。原典の区域が存在しないことにはならない。7つの段階を区別し、一段階の成功を後続の成功とみなさない | N §1.4（P-4）、§10.7、I §4.4 |
| 原則4 派生ジオメトリの分離 | 派生形状は原典の座標列を置き換えず、別の成果物で管理し、原典へ戻れる | N §10.4、I §6.2 |
| 原則5 無条件の自動修復の禁止 | `make_valid` の成功だけでは採用しない | N §1.4（P-6）、§10.6 |

## 8. Codex再監査に引き継ぐ論点

1. **位相的な無効を拒否しない変更の妥当性**: 第4章の安全策（判定保留・除外の禁止・unknown・公開準備状態）で、旧契約の安全性が維持されているか。
2. **外接矩形による確定的な除外（I §4.4の1）の論証**: 「どの解釈でも区域は元の頂点の外接矩形の中にある」という構成上の性質が、全分類（特に `other_undetermined`・真の交差・スパイク）で成り立つか。
3. **条件(c)の厳密な比較の方法**: ループの分解と包含関係による3解釈の比較が、頂点同士の接触以外（頂点‐辺の接触等）でも健全か。契約では頂点‐辺の接触は(a)で除外している。
4. **L1の範囲（全頂点の外接矩形）が影響を確実に包含すること**、およびL2の採用条件。
5. **2つの検証器の一致を `validation_error` の条件とすること**の是非（検証器の共通の誤りは検出できない）。
6. **公開準備状態の分離**が、既存のData Publish・Registryの責務と矛盾しないか。
7. **API契約への状態の引継ぎ**（I §10）で、`not_covered`・`unknown`・`outside_inundation_zone` が混同されないか。
8. 実測件数（第1章）が26成果品に限られることの扱い。
