### 3.3 リングの分解（座標列から読み取れる構造）［実測］

各リングを、繰り返し現れる頂点で単純なループに分け、向き（符号付き面積）と包含関係を厳密に求めた。

| 項目 | 結果 |
|---|---|
| 外周リングの向き | **7,038件すべて時計回り**。穴はすべて反時計回り（下記の4つを除く）。RFC 7946の推奨（外周は反時計回り）とは逆の向きで一貫している |
| 外周リングから分かれたループ | 5,743個。**すべて外周の内側にあり、外周と逆の向き（穴と同じ向き）** |
| 外周の外側に出るループ（外向きの葉） | 0 |
| 穴のリングから分かれたループ | 穴の内側を分け合う、穴と同じ向きのループ（2つの穴が頂点で接して1本のリングに書かれた配置） |
| 4頂点以下のループを含むポリゴン | 5,761 |
| 推定面積1 m²未満のループを含むポリゴン | 43（最小のループは約0.21 m²［推定。緯度35.7°での換算］） |

**構造から読み取れることと、推測の区別**:

- 推測［推定］: 格子状のセル（約5.6 m×4.6 m）から作った区域で、斜めに接するセルや、外周に角で接する空白セルを、1本のリングに書いた結果である可能性がある。**ただし原典のメタデータでは確認しておらず、作成者の意図は不明である。** 「外周と穴をまとめて記述したもの」と断定しない。

| 点の内外（偶奇規則を基準） | 254,079点（自己接触の頂点とその8近傍、接触点の近傍、外接矩形内の乱数点） | 非ゼロ規則・C-3・linework・structureのすべてが一致 |

**注意**: 無効な原典に対する `area`・`intersection`・`symmetric_difference` は意味が定義されない場合があるため、元の形状との面積比較は行っていない。比較は、厳密な点の内外（偶奇・非ゼロ）、派生形状どうしの位相的な一致、N03との判定で行った。**面積差0、有限個の点の一致、境界の一致は、派生形状が原典の意味と等しいことの証明ではない。**

## 10. Integrationへの影響

- 無効ポリゴンを、有効なポリゴンと同じ判定に混ぜない。統合成果物には、各区域に「原典の妥当性」と「使用した形状（原典／承認された派生形状）」の属性を持たせる［提案］。
- 地域の選別（I §4.1）で無効ポリゴンを扱う場合、その判定は「判定保留」であり、Integrationを失敗させるか、OWNERが承認した派生形状で判定するかを決める必要がある（現行契約では判定保留はIntegrationの失敗）。
- 案Cを採る場合は、派生形状ごとに次を記録する: 原典Featureの参照（ZIPのSHA-256・メンバー・Feature index・Polygon index）、原典の不正の分類、派生方法とパラメータ、使用ライブラリと版、変換前後の形状のハッシュ、検証の証跡（妥当性、元の頂点以外を使っていないこと、別方式との一致、解釈が分かれる領域の有無）、OWNER承認の参照。
- Integrated Validate に、派生形状について「同じ入力から再生成した結果が一致すること」「別方式（例: C-3とmake_valid）の結果が一致すること」「解釈が分かれる領域がないこと」を加える［提案］。

## 11. Flood APIの安全な応答

| ケース | 安全な扱い（提案） |
|---|---|
| 無効な浸水ポリゴン上の地点 | 案Bでは、その区域について「判定不能」を返す。**「区域外」「浸水なし」に変換しない** |
| 有効・無効のポリゴンが重なる地点 | 有効な区域の該当は返す。無効な区域は判定不能として併記する（有効な区域で該当しても、無効な区域のランクが分からないことを示す） |
| 無効ポリゴンの近傍 | 判定不能の範囲は、無効ポリゴンの頂点の外接矩形に限られる（どの解釈でも、区域は元の辺で囲まれた範囲を出ない）［構成上の性質］。外接矩形の外は、その無効ポリゴンの影響を受けない |
| 無効ポリゴンが広範囲を覆う場合 | 外接矩形による範囲の特定は保守的で、広くなりうる（荒川 fi=145917は外周の推定面積約152 km²）。その範囲を判定不能とするか、承認された派生形状を使うかの判断が必要 |
| 無効ポリゴンが対象地域の境界に重なる場合 | 地域の判定（N03）とは独立に扱う。無効ポリゴンの判定不能は、地域内外の判定を変えない |
| 同一形状に複数の出典・異なるランク | 4成果品の無効ポリゴンには、成果品をまたいで同一の形状はなかった（0件）。既存の原則（形状だけで重複を除かない）を維持する |

**影響範囲の特定について**:

- 頂点どうしの接触だけの形（本データの全件）では、**解釈が分かれる領域を厳密に計算できる**。ループの包含関係と巻き数・偶奇の比較で、解釈が分かれるループを特定でき、本データでは神田川 fi=10841 の4つの穴（約5.8 ha）だけだった。
- それ以外の領域では、偶奇規則・非ゼロ規則・GeoJSONの構造による解釈・C-3・make_validのすべてが一致する。
- したがって、判定不能の範囲を「無効ポリゴン全体」から「解釈が分かれる領域」まで狭める設計は技術的に可能である［実測による根拠。ただし、それが作成者の意図と一致することは未確認］。
- 交差・重複・スパイクを含む形（本データにはない）は、この方法で範囲を特定できない。その場合は無効ポリゴンの外接矩形全体をunknownとする方が安全である［提案］。

## 12. 推奨案と根拠

**推奨（未承認の提案）: 案Bを基本とし、案Cは分類を限定してOWNERが承認した場合だけ使う。**

1. **既定は案B**（原典保持＋判定保留）。無効ポリゴンは分類して記録し、APIは判定不能を「区域外」「浸水なし」に変換しない。
2. **案Cの適用候補**は、次のすべてを満たす分類に限定する:
   - (a) すべての接触が既存の頂点どうしの接触である（新しい交点がない）
   - (b) 真の交差・辺の重複・スパイク・面積0のリングがない
   - (c) 偶奇規則・非ゼロ規則・GeoJSONの構造による解釈が全域で一致する（ループ解析で厳密に確認）
   - (d) C-3とmake_valid（linework・structure）が位相的に一致し、すべて有効
   - (e) 元にない頂点がない

   本データでは7,037件がこの条件を満たし、1件（神田川 fi=10841、条件(c)を満たさない）は満たさない［実測］。
3. 条件(c)を満たさないもの、交差などを含むものは、案Bのまま判定保留とする。
4. 根拠:
   - 本データの無効の原因は、全件が頂点どうしの接触だった。
   - 派生形状は元の辺だけで作れて、座標を加えない。
   - 3方式の結果が全件一致し、解釈が分かれる領域も厳密に特定できた。
   - ただし、**派生形状が作成者の意図を表すことは確認できない**ため、自動採用ではなくOWNERの承認を前提とする。
   - 公開する場合は、派生形状を使ったことと、その根拠を示す必要がある（利用規約の「加工の表示」とも関係する）［未決定］。
