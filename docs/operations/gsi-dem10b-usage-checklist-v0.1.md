**照会先**: 国土地理院 地理空間情報部 情報企画課 審査係（[測量成果の利用手続](https://www.gsi.go.jp/LAW/2930-index.html) のお問い合わせフォーム、または 029-864-1111（代表））

**質問事項（案）**:

1. 地理院タイルの「標高タイル（基盤地図情報数値標高モデル）」DEM10B `dem_png` は、測量法上の基本測量成果として扱われますか。
2. Z14の限定したタイル（例: 東京都内の数十タイル）を事前に取得し、自社サーバーに保存する場合、測量法第29条（複製）の承認は必要ですか。
3. 保存したタイルを整数cmのJSONに変換し（値の補間なし）、利用者が指定した1地点の標高値だけをWeb APIで返す場合、第30条（使用）の承認、または承認申請は必要ですか。営利・非営利で扱いは変わりますか。
4. 上記の場合に推奨される出典表示の文言（加工の表示を含む）はどのようなものですか。APIの応答に含める文言として、「出典：国土地理院（標高タイル（基盤地図情報数値標高モデル）DEM10B）を加工して作成」で適切ですか。
5. 標高タイル（`dem_png`）のDEM10Bの値は、2025年の標高成果改定の前の値のままと理解してよいですか。今後更新される予定はありますか。
6. 取得の頻度・間隔について、守るべき上限はありますか。

回答は、日付・照会番号とともに記録し、承認記録の `approval_basis_ref`・`publication.eligibility_ref` から参照する。
